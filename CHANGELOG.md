# Changelog

## v0.1.2 (2026-11-20)

Linux one-line installer: installs kitty, mpv, fzf, the font and ANI.KOR, and adds an ANI.KOR app-menu entry that opens in its own styled kitty window (your kitty settings aren't touched). Tab in the video now goes to the episode list.

## v0.1.1 (2026-11-19)

Updates are now button-only: ANI.KOR never updates by itself. When a new version is out, click the pink UPDATE button (or press U).

## v0.1.0 (2026-11-18)

First ANI.KOR release: poster dashboard, MyAnimeList sync, working anime source (no ani-cli needed), Windows installer with auto-update.
